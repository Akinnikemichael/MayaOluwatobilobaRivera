# Maya Rivera — Redesigned storefront

This is a responsive HTML/CSS storefront concept based on the publicly visible state of the supplied Shopify URL.

IMPORTANT:
The supplied Shopify storefront is currently password-protected, so the public page does not expose its catalogue, product names, product images, collection handles, prices, or product URLs. The product cards in this version are intentionally marked as demo placeholders rather than inventing catalogue data.

To make this a complete catalogue-accurate build:
1. Provide a Shopify product/collection export (CSV is ideal), OR
2. Temporarily make the Shopify storefront public, OR
3. Provide screenshots / a list of products and collection URLs.

Then replace the demo product cards with every real product, image, price and exact URL.

Known Shopify links already wired:
- Home: https://mayarivera.myshopify.com/
- All products: https://mayarivera.myshopify.com/collections/all
- Cart: https://mayarivera.myshopify.com/cart
- About placeholder: https://mayarivera.myshopify.com/pages/about

Open index.html locally to preview the site.
